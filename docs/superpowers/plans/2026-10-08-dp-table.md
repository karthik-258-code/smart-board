# DP Table Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a reusable, reversible DP table with labeled cells and dependency arrows.

**Architecture:** Add a strict `table` object to the document registry and table operations to the existing deterministic state engine. Render it in SVG and expose cell/dependency editing through the existing inspector; generic object lifecycle and persistence then work without special cases.

**Tech Stack:** React, TypeScript, SVG, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-08-dp-table-design.md`

## Global Constraints

- Board document schema remains version 1; new object type uses typeVersion 1.
- Invalid operations leave input board unchanged.
- Rendering does not own semantic state; changes flow through BoardOperation.
- Existing local save, recovery, and history behavior remains intact.
- Add no runtime dependency.

## Review Focus

- Zero, negative, and oversized dimensions: reject malformed tables; generated table is 3×3.
- Null cell vs empty string: render null as blank and preserve empty string explicitly.
- Repeated dependency and self-dependency: reject duplicate edges; allow self-edge only if spec-driven? Decision: reject self-edge as unhelpful recurrence noise.
- Deleting a dependency endpoint: dependency list updates atomically when cell grid remains fixed; endpoint removal is unavailable in this slice.
- Persistence of nulls, labels, coordinates, and edges: preserve exact model through save/load.

### Task 1: Model and validation

**Files:** `src/domain/model.ts`, `src/domain/objectRegistry.ts`, corresponding tests.

- Add `TableCell`, `TableDependency`, and `TableObject` types; include `table` in `BoardObject`.
- Validate positive row/column dimensions, exact cell matrix shape, string/number/null values, labels, highlighted coordinates, and unique valid non-self dependency edges.
- Test valid table, malformed dimensions/cell matrix, out-of-bounds highlights/edges, duplicate edges, duplicate IDs, and strict unknown fields.

### Task 2: Reversible table operations

**Files:** `src/domain/operations.ts` and tests.

- Add operations `table/set-cell`, `table/set-highlighted-cells`, `table/add-dependency`, and `table/remove-dependency`.
- Validate target type and all coordinates before updating; return inverse operations/state sufficient for undo/redo.
- Test normal changes, undo/redo, invalid target/coordinates, duplicate or self edges, and unchanged state after failure.

### Task 3: Table renderer and creation

**Files:** `src/app/BoardToolbar.tsx`, `src/app/App.tsx`, `src/canvas/ObjectRenderer.tsx`, new table renderer, CSS, tests.

- Add `Add DP table`; create a 3×3 table with labels `0..2`, all cells null, no highlights, and no dependencies.
- Render accessible SVG grid with row/column labels, blank/value cells, highlight styling, and directed arrows.
- Reuse generic selection, drag, duplicate, remove, history, and persistence flows.
- Test accessible cell labels, values, highlights, dependency direction, add/duplicate/move/save interactions.

### Task 4: Inspector interactions

**Files:** `src/app/BoardInspector.tsx`, `src/app/App.test.tsx`, new component tests as useful.

- Show row/column selectors, cell editor, highlight toggles, and dependency source/target selectors for selected table.
- Disable invalid choices; report operation failures through existing app error region.
- Test assignment parsing, null/empty distinction, highlight toggling, dependency creation/removal, and selected table persistence.

### Task 5: Verification and commit

- Run focused domain and app tests, full suite, `npm run build`, and `git diff --check`.
- Update README implemented status and architecture status for the DP table.
