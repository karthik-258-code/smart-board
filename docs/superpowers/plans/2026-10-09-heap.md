# Heap Implementation Plan

> **For agentic workers:** Executed autonomously under the user's project-wide instruction.

**Goal:** Add visual min/max heaps with reversible push and extract-top operations.

**Architecture:** Store level-order values with a min/max invariant. Domain helpers perform heapify operations; renderer projects the values as array cells and a binary tree.

**Tech Stack:** TypeScript, React, SVG, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-09-heap-design.md`

## Global Constraints
- Keep schema version 1 and dependencies unchanged.
- Heap mutations stay one undoable history operation each.

## Review Focus

- Repeated equal values remain valid.
- Undo/redo preserves exact array order.
